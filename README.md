# 盆栽 — BONSAI

画像素材や外部APIを使わず、HTML・CSS・JavaScriptで育てる盆栽。
黒松・楓・梅を剪定し、曲げ、葉をすいて、自分だけの姿を作ります。
完成したら評議会の講評を受け、名前を付けて図鑑に保存できます。

## 今回の小規模改善

- 剪定する枝と子枝を橙色で事前表示し、別ボタンで確定。
- 剪定・曲げ・葉すき・成長を最大20手戻せる。
- 枝の選択範囲を拡大し、キーボードでも選択可能。
- 子枝を親枝の先端に接続。盆栽を各画面の枠に合わせて自動縮小。
- 鉢・樹皮の陰影、静かな展示背景、操作ガイド、動きを減らす設定への対応。

既存の図鑑保存キー `bonsai_gallery_v1` とデータ形式は維持しています。
図鑑は使用中のブラウザー内に保存されます。
